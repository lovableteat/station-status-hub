# Portable Markdown Handoff Implementation Plan

**Goal:** 更新目前 Markdown 說明，補齊功能、使用方式、資料邏輯、UI 契約及跨電腦重建流程；將專案 Markdown 集中複製到 `機台管理系統.md` 資料夾。

**Architecture:** 原始文件仍保留在原路徑，避免破壞程式或 AGENTS 的引用。新增四份領域手冊與導讀，更新 README、architecture；集中包採單層路徑前綴檔名處理同名衝突，內部 Markdown 連結對應新檔名，程式碼及資產連結指向本次版本的原始碼。

**Tech Stack:** Markdown、Node.js 內建檔案與雜湊功能；不新增依賴，不修改產品執行程式。

## Global Constraints

- 全部文件指本專案 Markdown（含被 Git 忽略的歷史任務、隱藏工具計畫與審查文件），不打包 node_modules、.git、dist、tmp、私密設定或第三方套件文件。
- 不移動或刪除原始文件；歷史紀錄保留日期，不把歷史計畫寫成目前功能承諾。
- 不匯出 .env、token、使用者帳密、API 金鑰、正式資料或檔案附件，不對正式服務做寫入或重新部署。
- 本次只驗證文件與集中包，不將歷史測試結果宣稱為本次全產品驗證。

## Verification

以 `git ls-files` 與本次新增文件建立來源集合；每份來源都有唯一集中檔案，來源 SHA-256 與輸出 SHA-256 記在索引（重新寫連結時雜湊可不同）。檢查輸出連結、UTF-8、對照數量與第二次產生後的雜湊；最後 `git diff --check`，確認僅文件／匯出檢查工具變更。
