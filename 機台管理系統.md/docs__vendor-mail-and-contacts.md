# 供應商信件與聯絡簿

入口：料號申請 → 待處理料 → 信件生成。

## 信件主旨

- 依目前 BOM 名稱、廠商與料件數量自動產生，每家廠商各一封。
- 在「廠商分組預覽」直接修改「信件主旨」；「自動產生」只還原該廠商主旨。
- 手改主旨隨本次視窗保留，重新整理不保存；空白主旨不可匯出。
- 原有信件開頭、簽名檔與圖片功能維持不變。

## 匯入及編輯聯絡人

1. 開啟「供應商聯絡簿」，可下載只有欄名的「空白範本」。
2. 選擇 Excel（xlsx／xls）或 CSV。「廠商」和有效的「Email」為必要欄位；其他欄位為聯絡人、副本、電話、備註。多個地址可用分號、逗號或換行分隔。
3. 檢查匯入預覽的有效、新增、重複及錯誤列數，確認後才按匯入。錯誤列不匯入；既有聯絡人及人工備註不覆蓋。
4. 「新增聯絡人」或每列「編輯」可手動增修，按儲存後寫入目前帳號的雲端聯絡簿。儲存失敗保留草稿；另一視窗已更新時會提示重新載入，不以舊資料覆蓋。

同一廠商（忽略頭尾空白、英文字母大小寫）且相同的收件人 Email 集合視為重複。沒有別名猜測；廠商名稱不同時請手動修正。多個聯絡人依廠商合併收件人及副本，並移除重複地址。

限制：單檔 5 MiB、50 張工作表、256 欄、合計 10000 列資料，每次最多 5000 筆有效聯絡人；超限明確拒絕，不靜默裁切。電話前導零依原始文字或 Excel 顯示格式保留。

## 匯出與資料邊界

- 匯出 HTML 提供各廠商的主旨、收件人、副本，以及獨立複製主旨／收件人／純文字／表格版本的操作，仍須自行貼入郵件軟體寄出。
- 不會自動寄信，也不把聯絡清單交給 AI 分析。
- 聯絡簿僅目前正式登入帳號可讀寫，未登入或訪客不可儲存；不混入 BOM 或全員共用偏好。
- 資料表為 `workspace.supplier_contacts`，來源 migration 為 `20261026095758_supplier_contacts.sql`；新增匯入不刪除資料，手動編輯使用伺服器版本時間檢查。
