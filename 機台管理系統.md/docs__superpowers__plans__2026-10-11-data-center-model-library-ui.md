# 模型與設備庫 UI 重整

## 範圍與設計

僅重排 Data Center 的 ModelLibrary，保留既有深色／青綠／琥珀配色、所有 callbacks、權限、相容性、U 位排除、刪除保護與匯入／編輯流程。不得修改正式機櫃或模型資料。

- 桌機：左側模型目錄，右側選中模型資訊與次要管理動作。窄螢幕改為上下排列。
- 使用緊湊的模型列、明確選取狀態與尺寸／類型資訊。搜尋、類別與可清除條件緊接結果區上方。
- 主要套用／新增／安裝按鈕固定在視窗底部，是真正的操作，不再是捲動捷徑。明示目標機櫃、唯讀、已套用、不相容與沒有可用 U 位狀態。
- 移除重複框線與工作模式頁籤列；匯入放獨立工具列。內建模型不可刪除改為保護說明，非內建模型保留確認框。
- 不新增依賴、頁面、設定或模型資料欄位。

## 執行與驗證

1. 先更新流程回歸測試，使新的雙欄、明確選取和直接操作契約在舊碼失敗。
2. 重排 ModelLibrary JSX，新增僅作用於該視窗的 token 樣式，保留原有匯入與編輯內容。
3. 執行 Data Center／facility 回歸、範圍 lint、typecheck、build，以及設計 detector。
4. 實際瀏覽器檢查桌機、短桌機及手機：切換模型類型、搜尋／條件清除／空結果、選取、不相容、U 位選擇、模型預覽、編輯取消與匯入返回；確認沒有水平溢出、遮住主動作或 console error。
5. 獨立審查、提交與推送 main，確認 Pages 部署與正式畫面。實體手機和正式資料寫入不列入這次 UI 驗證。

## 追加：模型細節側欄分類

使用者補充要求模型細節分類更明確。比較只加分隔線、分頁切換、可見的分類標題後，採用可見標題：不用增加切換步驟，也能辨識不同工具的目的。

- 「顯示模式」只放實體／透視／線框；「剖面檢視」保留開關及緊接的剖面位置；「視角控制」放重設視角；「零件結構」保留搜尋及零件可見性；「模型規格」放尺寸、原始檔及用途。
- 使用既有 secondary 背景與 border 的完整標題列，16px 組間距、8px 組內距；不更換網站配色、字體或新增依賴。
- 桌機側欄 280px、16px padding；手機維持模型畫布在上、可捲動工具在下，規格不再隱藏。零件名稱可換行，不依檔名猜測零件分類。
- 僅修改 DataCenterModelViewer JSX、作用域 CSS 與既有 viewer/mobile 回歸。保留 callbacks、模型幾何、相機、剖面及零件處理，不改配置資料或權限。
