# 依照片填表

入口：料號申請 → 待處理料 → **AI 依照片填表**。

1. 搜尋並指定料件（完整 MPN 必填）。候選料件沿用待處理料的替代廠商勾選範圍，不受當時分類或文字搜尋限制。
2. 貼上、拖入或選取要填寫的表格照片。照片定義欄位與順序，並不是 SPEC 資料來源。
3. 勾選此料件已保存的 SPEC，或從電腦加入 PDF、PNG、JPG、WEBP、TXT、CSV、TSV、MD。原有 GLB、STP 等工程附件仍可正常上傳與下載；STP／STEP 可提取模型外框等幾何摘要，但不能當成電氣規格或工程圖公差。
4. 選擇現有 AI 服務，按「開始依照片填表」。僅傳送這顆料的識別資訊、照片、所選 SPEC 與選填的查找條件；不傳整份 BOM，不自動改寫料件。
5. 複製表格貼到 Excel，或下載含「依照片填表」「來源查核」的 Excel。展開各數據旁的來源可看文件、頁碼與原文。

## 資料與權限

- 維持現有 Supabase 登入、API key RLS、SPEC Storage RLS、AI 用量紀錄與 OpenAI relay；不新增公共 bucket、service role 或放寬權限。沒有可用模型時須由管理員依原有流程設定服務與權限。
- 本機加入的照片與 SPEC 只保存在本次視窗記憶體；不寫入 BOM、localStorage 或附件資料表。按分析才送到所選 AI 服務。
- 單次最多 20 份 SPEC，照片與 SPEC 合計 18 MB。可分次選擇相關文件或頁面；不要求壓縮檔案。上傳與儲存的原始工程檔案限制不受此 AI 分析上限影響。
- 取消、關閉、切換料件、BOM 或帳號會取消或丟棄未完成的結果，不能把舊料件結果帶進新帳號／新料件。
- 沒有來源文件、頁碼、原文證據，或未確認 SPEC 對應完整型號的值，顯示「待確認」。模型判讀仍需由使用者依原文查核；網站沒有把 AI 輸出當作已驗證的工程規格。

## 驗證

- 使用隔離資料操作實際元件：待處理料入口、Ctrl+V 圖片、SPEC 勾選、一次加入十檔、開始／停止、錯誤保留、來源展開、複製及下載 Excel。
- 1440、1159、768、390 px 寬度檢查；390 px 下視窗寬 390 px，沒有整頁水平溢出，長結果表格在自身區域水平捲動。
- 單元驗證涵蓋照片欄位保留、MPN 不符、無來源數據、錯誤回應、取消與晚到結果、跨料件／帳號狀態、三種服務商的原生 PDF／圖片請求、十份未壓縮 SPEC、Excel 字串與來源往返，以及既有週報與待處理料範圍。
- 隔離瀏覽器驗證使用合成料件與受控供應商回應，確認返回、對話、來源及 Excel 流程；此驗證不代表任意真實 SPEC 的辨識準確率。
- 正式建置與變更檔案 lint 通過；本輪全專案型別檢查通過。


## 2026-11-04：對話、判讀與返回流程

- 固定顯示返回鍵、料件 MPN、模型與判讀模式。桌面表格使用完整內容寬度；平板及手機只在表格內左右捲動，不縮小資料字體。對話輸入固定在視窗底部，第一次分析失敗也能繼續操作。
- 可只選 SPEC 直接提問，不必先貼表格照片。「送出問題／追問」只回覆問題及引用，不改動已有表格；「依問題更新表格／重新填表」才會重新產生完整表格。加入照片後仍依每張原圖保留獨立欄列與 Excel 分頁。
- 「精細判讀」沿用管理員已設定的模型與授權。GPT-5 使用較高推理強度及 32,768 輸出預算，照片採 high detail；標準模式使用較小預算。並非任意替換模型或保證數值正確。Gemini 2.5 使用其支援的 JSON Schema 與 thinking budget；其他工具的預設參數不變。
- OpenAI 轉送函式只接受經驗證的推理、輸出長度、JSON Schema 及 store:false 選項，既有 JWT、金鑰讀取權限、已設定模型與官方端點檢查不變。
- 偵測供應商回覆截斷、拒答、追問漏掉前一張表格的欄列、未知來源和過長欄位。這些情形顯示錯誤，保留前一次成功結果，不以裁切後資料冒充成功。可讀文字 SPEC 的引用須能在所選原文中找到；PDF／圖片引用仍需人工核對。找不到證據顯示待確認，不補造數字。
- 來源按鈕可開啟完整引用、頁碼與原檔下載。來源格數是證據標示數量，不是準確率。原型號、單位、Min／Typ／Max 與測試條件仍須逐項查核。
- 瀏覽器上一頁與「返回待處理料」均回到原清單，保留清單搜尋／分類／捲動、照片、SPEC、歷次結果和未送出問題。只在本次同帳號、同 BOM 的頁面記憶體中保存；重新整理不持久保存私人檔案，切換帳號、BOM 或失去權限會作廢。正在進行的分析在離開時中止，晚回覆不得附到另一帳號。
- 導覽只在既有 workspace history 中加入位置標記，不把照片、SPEC、對話、金鑰寫到網址或 history state，不變更 project／fileSpace 等導覽上下文。

新增驗證包含模型參數白名單、截斷／來源／欄列保護、SPEC-only 對話、瀏覽器返回與前進、取消分析、權限／帳號隔離及完整 Excel。畫面驗證採合成料件和受控 AI 回應；這不等於已驗證任意真實 SPEC 的辨識準確率。
