## 安全與既有資料

- 引擎判斷與原始 52 個檔案以 manifest 驗證；不改動既有規則、人工回覆、追蹤 key 或資料庫權限。
- `single` 與 `run` 共用檔案數量、大小、安全相對路徑、YAML 和帳號操作檢查；伺服器處理完畢清理暫存。預設本機處理不傳送工程檔。
- PDF.js 的 CMap、標準字型與影像解碼資源由網站自己提供；另修正 ReportLab 的 MSung-Light 預設 GB／CNS 字碼不一致，繁體中文內容不變。PDF.js 只收到報表 buffer 的副本，避免 worker transfer 導致備份內原檔被清空；切換頁／比對時取消渲染並銷毀文件。
- 唯讀帳號可查看／匯出，不能新增比對、畫圖、回覆、記錄位置或匯入；切換帳號／比對後晚到的儲存不得污染新工作區。
- A HTML 與 DRAWIO 使用各自副檔名避開同名檔；任何一個 renderer 失敗，仍保留其他成功報表並提示。
