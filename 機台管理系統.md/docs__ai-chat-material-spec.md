# AI 問答的料號／SPEC 來源

在 AI 問答頂部點「維修資料 · 料號／SPEC」，開啟「料號／SPEC」，預設搜尋目前帳號可讀取的全部 BOM，包含歷史／封存；也能指定一份 BOM。維修資料開關獨立，兩個來源可一起使用。後續問題會連同最近三個使用者問題重新檢索，不需重選附件。

每次查詢都重新列舉 BOM 與全部廠商紀錄，分頁讀完後才建立附件清單，兼容舊版單一附件與多附件。同一 Storage 路徑只下載一次，保留各料件關聯。不以副檔名排除附件，也不只依檔名搜尋；解析內容後才挑選相關片段。

## 格式與可核對範圍

| 格式 | 讀取方式 |
| --- | --- |
| PDF | 逐頁文字，另送原 PDF 給所選 AI 核對圖表／掃描內容 |
| PNG、JPEG、WEBP、GIF、BMP、TIFF | 圖像由所選 AI 判讀；TIFF 分頁；GIF 靜態畫面 |
| XLS、XLSX、XLSM、XLSB、ODS | 工作表儲存值；不執行公式／巨集；新版封裝內嵌媒體另列 |
| DOCX、PPTX、ODT、ODP | 正文、頁面／投影片、註解等文字及內嵌媒體 |
| ZIP、RAR、7z | 在 Worker 的記憶體檔案系統解壓，遞迴處理各項，不執行檔案 |
| STEP／STP、STL、OBJ、PLY | 模型名稱、幾何近似外框與明文屬性；不推測電氣額定值、公差、接腳安裝深度 |
| GLB／GLTF、DXF、DWG、OrCAD 等原生工程檔 | 可辨識文字／結構；不宣稱完整讀懂原生圖面、外部依賴或幾何 |
| 其他檔案 | 仍嘗試文字讀取；二進位只能取得片段或標示未讀 |

「全部檔案」代表全部納入嘗試與報告，不代表所有專有二進位格式都已有完整轉換器。每次回答附逐檔狀態、原因與原檔下載，引用 `[S編號]` 可對照。AI 圖像判讀始終標示部分解析，需核對原檔。

單檔解析 50 MB；單一壓縮檔最多 500 項／解壓 100 MB；累計展開 200 MB、最多加入 5000 項、深度 3 層。加密、缺分卷、不安全路徑、容量／時間超限、權限不足均明列未讀。原始清單超過 5000 份仍逐份嘗試；5000 上限控制新展開項目。模型原生附件每批最多 4 份／16 MB；失敗後停止後續圖像批次，保留文字與逐檔失敗原因。依問題選取的模型上下文最多 8 萬字元，超出明示範圍限制。

## 權限與儲存

只使用登入帳號既有 Supabase RLS／Storage 權限；沒有新增資料表、角色權限或服務金鑰。帳號切換、權限撤銷、新對話與元件卸載會停止舊檢索。附件內容不快取至其他帳號，不寫入 BOM；對話只保存回答及來源報告，不保存全文、原始附件或簽名網址。文件文字一律視為不可信資料，不是可執行指令。
