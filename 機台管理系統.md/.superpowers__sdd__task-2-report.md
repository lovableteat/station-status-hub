## GREEN 最小實作

### `src/components/pcb-designer/core/files.ts`

- 將 `MAX_IMPORT_FILE_BYTES` 由 `5 * 1024 * 1024` 提升為 `50 * 1024 * 1024`
- 超限訊息改為 `檔案大小超過 50 MB 上限。`
- 維持在任何內容讀取前先檢查檔案大小

### `src/components/pcb-designer/PcbDesignerWorkspace.tsx`

- 擴充 import preview 對話框資料：
  - `importKind: "library" | "bom"`
  - `totalCount`
  - `placementCount`
- 新增乾淨的 library / BOM preview handlers，避免動到 Task 1 禁止範圍
- library preview 傳：
  - `importKind: "library"`
  - `totalCount = valid + errors`
- BOM preview 傳：
  - `importKind: "bom"`
  - `totalCount = valid + errors`
  - `placementCount = result.placementCount`
- commit callback 維持既有 commit/cancel 行為

### `src/components/pcb-designer/PcbDialogs.tsx`

- `PcbDialogState["import-preview"]` 擴充欄位
- 將預覽摘要改為可理解模式：
  - 總列數
  - 有效筆數
  - 錯誤筆數
  - BOM 額外顯示待放置筆數
- BOM 顯示說明：
  - 建立左側待放置清單
  - 不會直接放到畫布
- action label 依 `importKind` 切換：
  - library: `匯入元件庫`
  - bom: `建立待放置項目`
- `validCount === 0` 時 disable action
- 錯誤顯示上限：
  - `dialog.errors.slice(0, 100)`
  - 若超過 100，額外顯示尚未列出的錯誤數
