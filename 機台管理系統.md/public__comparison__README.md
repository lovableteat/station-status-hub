# Browser AutoCheck runtime

`engine/` contains the user's AutoCheck 0.2.0 engine, currently from `AutoCheck_1027.zip` (2026-10-27, see `docs/autocheck-1027-integration.md`; earlier updates are described in `docs/autocheck-1015-integration.md` and `docs/autocheck-1022-integration.md`): 48 original Python modules and four configuration files. Every imported file is unchanged and listed with its SHA-256 in `engine/manifest.json`, together with the source ZIP checksum. Against the deployed previous package, 16 files changed, five were added, and 24 remain identical. The ZIP's virtual environment, Streamlit UI/preferences, backups, review database, datasets, static reports and PDFs are excluded. The supplied user library still has `devices: []`.

The update adds Agile PLM BOM parsing (including approved substitutes and socketed `FOR J2` parts), power-converter/feedback voltage inference and its part library, I²C second-source checks and a simplified block diagram, plus rotated/cropped PDF normalization. The existing React workspace, required inputs, feedback, account storage and folder Datasheet workflows are retained. Only the chart toolbar adds internal-net and detail/simple view controls; downloaded HTML retains the upstream standalone tools. HTML scripts are never embedded into the app: charts remain sanitized SVG with React controls.

Two explicit compatibility adapters run before `browser_bridge.py`. `browser_compat.py` preserves physical PDF dimensions when the source uses a non-default `/UserUnit` and gives the new unresolved/orphan BOM rows identities that survive BOM reordering; previous tracking keys are preserved. `power_tree_compat.py` completes the update's voltage source/approximation/conflict presentation in SVG and Excel without changing voltage decisions. The bridge pins both I²C and power-library paths to bundled safe configuration, keeps recursive PDF discovery, and retains local PDF/Excel safety handling.

`autocheck.worker.js` loads Pyodide 0.29.3 on the first command and handles only the `run`, `tracker`, `library` and `datasheet` protocols. Inputs are written to a fresh in-memory directory for each command, removed afterwards, and never uploaded. Worker termination cancels execution. The worker validates relative paths, duplicates and file limits before initializing Python (1000 files, 64 MiB each, 128 MiB total). Rule/library YAML is limited to 2 MiB, uses `safe_load`, and rejects excessive nesting and circular aliases. Configuration cannot redirect the engine to arbitrary library/review/publication paths.

Pyodide packages: pandas 2.3.3, lxml 6.0.2, PyYAML 6.0.2, Pillow 11.3.0, cryptography 46.0.3, xlrd 2.0.1, and the bundled sqlite3 package. Pure Python packages are pinned to openpyxl 3.1.5, olefile 0.47, reportlab 4.4.10, pypdf 6.1.1, pdfminer.six 20251230, charset-normalizer 3.4.4 and pdfplumber 0.11.7. `pdfplumber` is installed without its optional image renderer `pypdfium2`; the original text/table and annotation paths work unchanged. Datasheet PDFs with only scanned images need manual candidate entry, as the original engine does not provide OCR.

The original project declared Python 3.12 / pandas 3.0. Pyodide uses CPython 3.13 / pandas 2.3.3; behavior is checked with the unchanged synthetic suite, rather than asserting identical dependency versions. ReportLab's Traditional Chinese `MSung-Light` CID font replaces the unavailable desktop font lookup at the adapter boundary. This preserves Chinese text but depends on the PDF viewer's CJK font support.

Run lightweight contract checks with `node --test tests/comparison/python-runtime.test.mjs`. The full runtime check is opt-in: install `pyodide@0.29.3` in ignored `tmp/autocheck-runtime` (or set `AUTOCHECK_PYODIDE_MODULE` to an external `pyodide.mjs` file URL), set `AUTOCHECK_PYODIDE=1`, then run the same test. It exercises actual parsing, Agile BOM/reordering, changes, capacitor derating, PDF annotation, original outputs including the new I²C block diagram, Excel replies, address-library signing, datasheet extraction and stable tracking keys. The original synthetic tests run separately without company datasets.
