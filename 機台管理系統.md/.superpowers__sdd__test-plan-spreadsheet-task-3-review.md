## Review notes

- `TestPlanSpreadsheetEditor.tsx:937-950` builds the tab model from the
  formatted workbook and resolves `worksheet.properties.tabColor` through the
  existing `resolveColor` function with the loaded workbook theme palette. This
  retains the established ARGB, indexed, theme, and tint resolution behavior;
  sheets without a resolved colour use the neutral fallback.
- `TestPlanSpreadsheetEditor.tsx:1248-1268` places the sole tablist directly
  after the scrollable grid and before pagination. Existing `role="tab"`,
  `aria-selected`, selection reset, and button activation behavior are retained.
- `test-plan.css:1245-1382` changes the workspace to a constrained column flex
  layout: the grid remains the shrinkable/scrollable region, while the footer
  and pagination retain their height. The tab strip has `min-width: 0` and
  `overflow-x: auto`; the 700px layout keeps that strip intact while other
  controls stack. Colour use is limited to the 3px indicator, active/hover
  border, and focus-visible outline, with neutral tab backgrounds.
- `tests/test-plan/ui-contract.test.ts:104-118` covers the new source contract
  for tab-colour lookup, custom property, footer styling, horizontal overflow,
  and placement after the grid. The production code was also inspected directly
  rather than relying on the source-contract test alone.
