# 公司供應商聯絡資料

使用者已確認：待處理料的「信件生成」旁新增「供應商聯絡資料」；公司有效帳號共用查詢，只有管理員修改。沿用黑底青綠、既有 Dialog／表格與持久篩選規範。原有私人聯絡簿不公開。

1. 建立獨立公司聯絡資料模型、來源追溯與 Excel 解析。支援不同表頭／檔名、實際合併範圍、同列業務與主管、缺 Email 仍可查詢；保留原欄位。測試僅使用虛構資料，原始聯絡資訊不得加入 Git。
2. 匯入先設定來源群組與欄位對應，再比較新增、變更、未變、需人工確認與本次缺少；顯示欄位前後值。選取後原子套用並檢查版本，不自動刪除、不默默覆蓋人工修改。Gemini 為選用檢查，送出前明示 Google 接收範圍，結果只供參考。
3. 資料庫獨立表、有效帳號讀取、管理員寫入 RPC；手動修改及匯入均檢查版本，批次有一筆衝突則全批不寫入。
4. 公司聯絡資料視窗提供搜尋、來源篩選、可清除條件、完整欄位詳情、複製、管理員編輯與匯入。信件依公司名稱／別名／明列代理品牌精確配對，顯示匹配來源與可調收件人；不猜測公司或自動寄信。
5. 以九份原始 Excel 私下核對筆數及異常；執行解析、差異、權限與 UI 測試、typecheck、lint、build，再套正式 migration、匯入確認資料、提交推送與驗證部署。

影響範圍：material-requests 新公司聯絡簿模組、PendingMaterialsDialog／PendingMailDialog、相關測試、單一 migration 與本文件。BOM／CE、私人聯絡資料、使用者其他未提交文件不改動。
