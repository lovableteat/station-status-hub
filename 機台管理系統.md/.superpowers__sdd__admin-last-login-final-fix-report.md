## Final changes

- `formatAdminUserTimestamp` now accepts only full ISO/PostgreSQL timestamptz values with `Z` or a UTC offset; timezone-less, malformed, and calendar-invalid inputs use the supplied fallback.
- Added JSDoc parameter and return types to the formatter.
- `SystemUser.last_seen_at` is now required as `string | null`.
- Moved `Clock3` to the `最後登入` label and removed it from `建立時間`.
- Uses a visually secondary `text-slate-500` value when the rendered last-login value is `尚未登入`.
- Reworked the permissions strip: the left side is one icon plus one truncatable `網站與工作區權限 · 建立者：...` summary with full `title` and `aria-label`; the workspace count badge is in the right badges area. Existing mobile two-row and desktop one-row responsive container classes remain intact.
- Source tests cover the timestamp acceptance/fallback cases, icon ownership, fallback class, required type, full accessible summary, truncation, right-side badges, and responsive one-line desktop structure.
