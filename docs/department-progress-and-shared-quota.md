# 部長總覽與全員 API 額度（2026-10-05）

## 問題與處理

正式資料本期只有一份課別彙整草稿，沒有已送交彙整。個人評核完成不會建立或提交 `performance_section_reports`，原總覽只列送交的彙整，因此部長看到全部為零。

總覽現在獨立讀取各課即時評核進度，不依賴彙整是否存在。四個指標顯示所屬課別人數、已完成評核、待主管評核、已送交成果彙整；各課卡片列明送交狀態。課長仍需自行送出成果與協助需求，系統不代為發布草稿。

`get_performance_department_progress` 只輸出計數與課別資訊。部長限直屬課長的課別，課長限自己的課別，必須為啟用且有績效管理權限的帳號並解鎖自己的保護範圍。沒有組織管理資格的帳號得到空清單。函式不輸出同仁姓名、分數、評語或草稿內容；停用帳號與未登入者無法讀取。各員工本期只採最新紀錄，兼容 UUID、帳號與既有唯一姓名識別。

AI 對話新增手機、桌面共用額度面板，沿用 `get_ai_model_usage_summary` 的 AI 工作區查看權限，無需 API 管理員權限。面板顯示所選 API / 模型的全員最近一分鐘與太平洋當日請求數，以及既有設定上限。它不讀取或顯示金鑰。

畫面可見時每 30 秒更新，完成請求、回到分頁或按更新也會重新讀取。避免重疊請求，12 秒逾時、離開畫面取消讀取、模型切換捨棄舊回應；讀取失敗呈現未知，不顯示假零。既有額度設定日期為 2026-10-04，本次沒有修改上限值。其他網站／金鑰的 Google 專案用量不在本系統統計內，因此剩餘量只提供估算範圍；token 使用量仍未知。

## 驗證

- PostgreSQL 隔離測試：主管範圍、草稿隱私、最新紀錄、跨期排除、停用與未登入、鎖定、只讀。
- 既有 AI 遙測 PostgreSQL 測試：跨使用者合計、模型獨立、失敗與重試、未授權拒絕，共 13 項。
- React 渲染：普通 AI 使用者讀到全員用量、離線不顯示假零、切換模型不混入舊結果、課別進度與共用篩選。
- 桌面及 390px 手機預覽使用模擬資料，檢查搜尋、送交狀態、清除條件、手動更新、展開說明及卡片間距。
- TypeScript 檢查及正式建置。
