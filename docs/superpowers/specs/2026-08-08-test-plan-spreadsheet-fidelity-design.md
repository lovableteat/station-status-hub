# Test_Plan 試算表顯示與延伸設計

## 目標

改善 Test_Plan 的 Excel 編輯器，使數值顯示符合原檔格式、列欄可以從目前選取位置自然延伸，並把工作表標籤移到表格下方且保留 Excel 分頁色。

## 採用方案

保留現有 ExcelJS／SheetJS 編輯架構，不更換試算表引擎。把可單元測試的格式與插入位置邏輯放進 `spreadsheetInteraction.ts`，大型函式與檔案載入仍由 `TestPlanSpreadsheetEditor.tsx` 負責。

未採用的方案：

- 只在工作表最後追加列欄：風險低，但使用者必須自行捲到最末端，且無法在目前資料附近工作。
- 導入完整試算表元件：功能較多，但會大幅增加套件、版型重做與原檔相容風險，超出本次需求。

## 數值顯示

- 儲存格保留原始數值與公式，不修改資料精度。
- 顯示時使用 SheetJS `SSF.format` 套用 Excel `numFmt`；`General` 格式也經 SSF 正規化，避免 `50.400000000000006` 這類 IEEE-754 尾數。
- 公式儲存格使用快取結果顯示，但公式列與編輯模式仍顯示公式本身。
- 格式器無法處理的值退回既有文字轉換，避免單一異常格式使整張工作表中斷。
- `xlsx` 維持動態載入，避免把大型試算表套件加入初始應用程式 bundle。

## 新增列與欄

- 「向下插入列」插在目前選取範圍最後一列的下一列。
- 「向右插入欄」插在目前選取範圍最後一欄的右側。
- 若插入點會切開合併儲存格，插入點移到該合併範圍之後。
- 新列複製上方列的高度與儲存格樣式；新欄複製左方欄的寬度與儲存格樣式，但不複製內容。
- 插入後自動選取新增位置並捲動到可見範圍。
- `.xlsx` 使用 ExcelJS 結構操作；相容模式使用明確的儲存格位移與 `!ref`／合併範圍更新，維持舊格式可編輯性。

## 工作表標籤

- 工作表標籤從頂部工具列移到表格底部，與一般 Excel 使用習慣一致。
- `.xlsx` 讀取 `worksheet.properties.tabColor`，沿用現有主題色、索引色與 tint 解析器。
- 色彩用於標籤底部狀態線與選取邊框；未設定分頁色時使用現有中性色。
- 頂部只保留復原、剪貼與新增列欄工具，降低工具列擁擠。
- 底部在窄螢幕可橫向捲動標籤，分頁與列數控制保持可操作。

## 錯誤處理與資料安全

- 插入與格式化失敗只顯示可理解的錯誤，不覆寫原檔。
- 原始值、公式、其他工作表及未操作儲存格不因顯示格式而改寫。
- 儲存仍走既有「儲存回原檔」流程，只有使用者按下儲存才上傳更新內容。

## 驗證

- 單元測試驗證 General、固定小數、百分比格式與格式器失敗退回。
- 單元測試驗證選取範圍下方／右方的插入位置及合併儲存格避讓。
- UI 契約測試驗證動態 SSF、底部分頁容器、Excel 分頁色 CSS 變數與新增按鈕文案。
- 執行全部 Test_Plan 測試、TypeScript/Vite production build、焦點 ESLint 與 Git whitespace 檢查。
