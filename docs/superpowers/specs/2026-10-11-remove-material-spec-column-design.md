# 移除 BOM 總表規格／備註欄

使用者指定移除截圖中的「規格 / 備註」欄。範圍為料號申請的 BOM 總表，不刪除任何資料。

- 直接移除桌機表頭、規格篩選、主料與替代料儲存格；不採 CSS 隱藏，避免空白欄與隱藏篩選。
- 十個剩餘欄位保持原順序、配色、功能；資料更新仍固定右側，欄寬及跨欄同步對齊。
- 舊十一欄的個人欄寬移除第九欄，保留其他設定；還原篩選僅接受目前存在的鍵，捨棄 specification 舊條件。
- 料件詳細資料、表單、搜尋資料、Excel／HTML 匯出中的規格與備註保留。
- 只操作檢視、展開、搜尋與個人欄寬，不新增、修改、刪除或匯入正式 BOM 資料。

選項自評：CSS 隱藏會留下邏輯與欄寬殘留；刪除資料欄位會造成不必要的資料損失。採用完整移除總表呈現且保留原資料的最小方案。檢查沒有跨工作區改動或新增依賴。

驗收：十欄的表頭／篩選／主料／替代料一致，資料更新固定正確；舊規格條件不影響結果，現有篩選仍可用。通過回歸測試、型別、建置與桌機／行動版目視後提交推送，核對 Pages exact SHA。
