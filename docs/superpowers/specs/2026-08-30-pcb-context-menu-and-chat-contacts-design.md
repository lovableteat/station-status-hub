# PCB 右鍵選單與聊天室聯絡人行動版設計

日期：2026-08-30

## 目標

1. PCB 2D 畫布使用自訂情境式右鍵選單，不再顯示瀏覽器原生選單。
2. 聊天室聯絡人在手機上改為兩欄、最多兩排，超過時上下捲動，不再左右拖曳。

兩項修改都只重用現有前端狀態與操作，不新增資料表、API 或持久化資料。

## PCB 情境式右鍵選單

### 互動

- 右鍵點擊元件、禁制區或量測線時，先選取該物件，再顯示物件操作。
- 若右鍵目標已在多選群組中，保留群組選取；若不在群組中，改為單選該物件。
- 右鍵點擊空白畫布時，清除物件選取並顯示畫布操作。
- 鎖定、唯讀或目前無適用目標時，對應操作顯示為停用。

### 選單內容

物件選單重用現有 workspace API：

- 複製 `Ctrl+C`
- 建立副本 `Ctrl+D`
- 旋轉 90° `R`（元件與禁制區）
- 鎖定／解鎖（元件）
- 刪除 `Delete`

空白畫布選單重用現有 workspace API：

- 貼上 `Ctrl+V`
- 復原 `Ctrl+Z`
- 重做 `Ctrl+Shift+Z`
- 放大／縮小
- 重設檢視 `F`

### 實作邊界

- 使用專案既有的 shadcn/Radix `ContextMenu` 元件。
- 選單透過 portal 呈現，避免被畫布 overflow 裁切。
- 不建立新的編輯命令或重複狀態；所有操作沿用鍵盤快捷鍵與工具列相同函式。

## 聊天室聯絡人行動版

### 版面

- 將聯絡人容器由單列 `overflow-x-auto` 改成兩欄 CSS Grid。
- 聯絡人卡片寬度由欄位決定，移除固定最小寬度造成的橫向溢出。
- 區塊高度限制為兩排卡片；更多聯絡人使用區塊內的直向捲動。
- 姓名維持單行截斷，狀態、頭像與在線標記保留。
- 每張卡片保持至少 44px 觸控高度。

### 行為

- 聯絡人排序、搜尋、在線狀態與開啟／建立私訊的資料流完全不變。
- 最近對話區維持目前位置，不因大量聯絡人被推到頁面底部。
- 聯絡人區不得產生水平 overflow。

## 驗證

- 先以契約測試確認 PCB 選單與聯絡人 Grid 尚未存在，再實作至測試通過。
- PCB：在桌面尺寸右鍵物件與空白處，確認選單內容、停用狀態與操作結果。
- 聊天室：在 390×844 與 320px 寬度確認兩欄、兩排、直向捲動且無水平 overflow。
- 執行完整 PCB 測試、相關協作中心測試、TypeScript、ESLint 與 production build。
- 瀏覽器實際目視並確認沒有框架錯誤覆蓋或相關 console error/warn。
