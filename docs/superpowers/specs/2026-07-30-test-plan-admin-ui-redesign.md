# Test_Plan 與後台管理一致化設計

## 目標

把目前過度空白的 `Test_Plan` 完成為可日常使用的工程檔案工作台，並把後台管理改成與「機台維修紀錄中心」相同的應用框架、配色、密度及側邊導覽。

## 已選方案

評估過三種做法：

1. 只微調現有 CSS。變更最小，但無法解決 Test_Plan 沒有檔案檢查流程、空狀態佔滿畫面，以及後台缺少側邊導覽的結構問題。
2. 另做全新工作區與資料模型。彈性最高，但會重複已完成的 Supabase 空間、資料夾、檔案及權限能力。
3. 保留可靠的資料層，重做資訊架構與互動層，並抽取維修中心既有的設計語彙。

採用方案 3。使用者已指定「機台維修紀錄中心」為視覺基準，且要求直接執行，視為對此方案的核准。

## Test_Plan 資訊架構

- 頁首：沿用維修中心標題、說明與主要操作，不再使用自成一格的大型漸層標頭。
- 摘要列：空間、資料夾、檔案、儲存容量四個緊湊指標。
- 左側：個人空間、空間操作、目前空間的巢狀資料夾樹。
- 中央：路徑、搜尋、格式篩選、排序、格狀／表格檢視、上傳區及檔案內容。
- 右側：所選檔案或資料夾的檢查面板。圖片、PDF、文字、Markdown 與 CSV 可直接預覽；Office、3D、PCB、壓縮檔顯示完整格式資訊與下載操作。
- 空狀態：顯示三步快速開始（建立空間、建立資料夾、上傳檔案），避免整頁只有一顆按鈕。

## Test_Plan 互動

- 建立及編輯空間可設定名稱、說明與識別色。
- 單擊項目會選取並顯示右側資訊；雙擊資料夾進入，雙擊檔案開啟預覽。
- 檔案仍支援拖放及按鈕批次上傳、重新命名、搬移、說明、下載與刪除。
- 預覽透過既有私有儲存下載取得 Blob，建立暫時 Object URL；切換檔案或關閉預覽時立即釋放。
- 不支援瀏覽器內預覽的工程格式不偽造內容，清楚顯示副檔名、大小、更新時間及下載入口。
- 所有既有權限、500 MiB 單檔限制、20 檔批次限制與安全刪除規則保持不變。

## 後台管理資訊架構

- 外層採用維修中心相同的 `#06111f` 內容底、`#071522` 側欄、`#2a526f` 邊框與 `#4c8dff` 選取色。
- 左側欄包含「用戶管理」、「通知與在線」及具權限時的「API 管理」。
- 側欄可收合；窄螢幕改為抽屜，保留標準鍵盤焦點與可辨識標籤。
- 內容頁首使用共用 `MaintenancePageHeader`，摘要使用 `MaintenanceMetricStrip`。
- 移除裝飾性漸層、光暈及過大的行政標頭；保留既有新增、停用、權限、編輯、通知與 API 操作。

## 元件邊界

- `TestPlanWorkspace.tsx`：頁面狀態協調、資料動作與三欄組合。
- `TestPlanSpaceDialog.tsx`：空間名稱、說明、識別色表單。
- `TestPlanInspector.tsx`：選取項目資訊、私有檔案預覽及下載。
- `test-plan.css`：維修中心一致的 Test_Plan 版型與響應式行為。
- `AdminSidebar.tsx`：後台側欄、收合與行動裝置抽屜。
- `AdminPanel.tsx`：既有帳號／通知／API 功能與新框架組合。
- `admin-panel.css`：後台外框及側欄響應式樣式。

## 錯誤與邊界狀態

- 預覽載入失敗只影響檢查面板，不會清空工作區。
- Blob URL 在選取變更及元件卸載時釋放。
- 檔案下載、預覽、上傳與資料操作各自提供繁體中文錯誤訊息。
- 唯讀權限仍能搜尋、檢視資訊、預覽與下載，但不能建立、搬移、重新命名或刪除。
- 後台側欄只顯示使用者有權檢視的模組。

## 驗收

- Test_Plan 空狀態有明確快速開始流程，建立空間表單包含名稱、說明與識別色。
- 上傳、拖放、搜尋、格式篩選、排序、格狀／表格、選取、預覽、下載、重新命名、搬移與刪除均有可操作入口。
- 圖片、PDF 及文字類檔案具實際 Blob 預覽；工程格式具誠實的資訊面板與下載。
- 後台管理具有可收合側欄，並與維修中心共用標題、指標與深色設計語彙。
- 桌面與窄螢幕無裁切、重疊、水平捲動陷阱或不可操作的主要按鈕。
- 聚焦測試、TypeScript、ESLint、正式建置及瀏覽器互動驗證通過後才可提交。
