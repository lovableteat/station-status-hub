# PCB Designer 專業工作區重設計

日期：2026-07-27

## 目標

把目前過度緊縮、操作入口不清楚的 PCB Designer，重做成與工作整合平台其他頁面一致的專業佈局規劃器。這次交付必須同時解決三件事：

1. 版面尺寸、字級、控制項和資訊層級與平台一致。
2. 提供真正可旋轉、平移、縮放及點選元件的 3D 檢視。
3. 讓既有專案、模板、元件庫、拖放、網格、禁制區、測量、DRC、復原重做、自動儲存及匯入匯出形成完整可理解的工作流程，並補上高頻元件操作。

本工作區定位為 PCB 佈局規劃器，不宣稱提供未實作的製造級 Gerber、Excellon 或 KiCad 原生輸出。

## 方案評估

### A. 僅放大現有畫面

變更風險最低，但仍無法解決功能難以發現、2D／3D 缺口及空白畫面缺少引導，不採用。

### B. 另開獨立 3D 頁面

能快速增加 3D，但使用者會離開編輯上下文，且容易產生兩份狀態，不採用。

### C. 單一專案、雙檢視專業工作區

2D 與 3D 使用同一份專案資料，切換時保留選取、圖層與檢查狀態。左右面板維持工作流位置，但改成平台一致的可讀尺寸與群組。採用此方案。

## 資訊架構

工作區由五層組成：

1. 專案列：標題、專案選擇、狀態、自動儲存、模板、設定及匯入。
2. 主工具列：檔案、歷史、2D 工具、縮放、2D／3D 切換、DRC。
3. 左側資產面板：專案、模板、元件庫及 BOM，支援搜尋、上傳與拖放。
4. 中央工作區：2D 精準編輯或 3D 即時檢視。
5. 右側檢查面板：板設定、選取物、圖層／顯示及 DRC。

桌面版左右面板寬度提高，控制項採至少 40px 高度、12–14px 文字；窄螢幕延續抽屜模式。中央畫布保留最大空間，但不再使用 10px 級主要文字。

## 2D 工作流

- 既有選取、平移、測量及禁制區工具保留。
- 元件可由元件庫或 BOM 拖放至板上，支援網格吸附及 Alt 暫時略過。
- 選取元件後可旋轉、鎖定、刪除，新增複製、Top／Bottom 翻面及置中板框。
- 空白板顯示開始引導，直接連到元件庫、BOM 與模板，不讓使用者面對無提示的空畫面。
- 工具列顯示文字與快捷鍵提示，高頻操作不只靠小圖示猜測。

## 3D 工作流

- 使用 `@react-three/fiber`、`@react-three/drei` 與既有 Three.js 依賴。
- PCB 由實際板寬、板高及板色生成有厚度的實體板。
- 元件依 2D 座標、寬高、最大高度、旋轉角及 Top／Bottom 層生成 3D 實體。
- 禁制區顯示為半透明區域；可切換元件、禁制區、網格及座標軸。
- 支援滑鼠拖曳旋轉、右鍵平移、滾輪縮放、點選元件、Top／Bottom／等角相機預設、重設視角及自動旋轉。
- 3D 點選與 2D／檢查面板共用同一個 selection，切換視圖不丟失上下文。
- WebGL 不可用時顯示明確錯誤與返回 2D 的動作，不呈現空白區。

## 完整性與資料一致性

- 2D 與 3D 不另存狀態；專案 JSON 仍是唯一資料來源。
- 舊 schema 專案可直接開啟，新增顯示偏好僅存本地工作階段，不破壞匯出相容性。
- DRC 在兩種檢視皆可執行；選取問題可定位到對應物件。
- JSON、PNG、BOM CSV／XLSX 與元件庫／BOM 上傳行為保持相容。
- 儲存提示必須如實表示本機自動儲存，不再暗示未啟用的遠端同步。

## 錯誤、空白與權限狀態

- 唯讀或文件鎖定時，所有會修改資料的操作一致停用。
- 空白專案提供可操作的新手引導。
- 3D 載入與 WebGL 錯誤有明確狀態。
- 匯入錯誤、DRC 問題及非法幾何持續使用既有安全驗證，不吞掉未放置 BOM 項目。

## 驗收

- 1920×900 下主要文字可讀、控制項高度與平台相近，左右面板不再過窄。
- 2D／3D 可在同一工作區切換，3D 能旋轉、平移、縮放及選取元件。
- 元件複製、翻面、置中、旋轉、鎖定與刪除皆可復原／重做。
- 原有 93 項 PCB 測試保持通過，新增核心與 UI 合約測試通過。
- ESLint、TypeScript/build 及實際瀏覽器桌面流程通過。
- 變更整合至 GitHub `main`，並確認遠端 commit 與本機一致。
