# 手機工作區 UI 重排

使用者標註 518px 手機畫面，要求維修中心問題儀表板、料號快查與 AI 問答重做 UI。範圍為小於 1024px 的既有操作畫面；保留黑底青綠、原資料、計算、欄位、文案、權限與儲存流程。

- 維修：一行模組導覽、整合四項問題指標，優先問題改成逐筆可點的清單，清楚分開嚴重度、狀態、機台、負責人與未更新天數。桌面保留原表格。
- 料號：搜尋與篩選持續放在結果上方，次要排序／匯入匯出移入工具選單；卡片標題可換行、資訊分層，Note 可展開編輯，原欄位與儲存回呼不變。
- AI：明確頁首、模型選擇獨立完整一行，保留對話紀錄、聊天室與新增對話。資料來源、額度與對話、輸入區分層，輸入區固定可操作，通知不蓋住頁首。
- 聊天浮鈕在手機縮為 44px 圖示，保留 accessible name 與未讀數，減少遮住內容。

沿用平台字體與 token，不新增依賴或圖片素材。驗證 518px、390px、320px 與桌面，涵蓋長文字、作用中條件、卡片與選單操作、AI 草稿／送出／對話紀錄；以隔離資料確認，正式資料不試寫。使用一次機械掃描與一次整批目視審查，集中修正後複核。

## 驗證結果

- 518×884、390×844、320×700 及 1280px 桌面已目視確認。三頁窄版沒有頁面橫向溢出；桌面保留表格／側欄。手機料號搜尋可顯示並清除條件，工具選單可開啟欄位設定，Note 可展開保存。
- 隔離 AI 對話已確認新增、送出、接收回覆及切換模型；共 74 項相關導覽、版面、Note 衝突處理、搜尋、對話生命週期與帳號隔離檢查通過。TypeScript、修改元件的 ESLint 與正式建置通過；建置仍有既有的大型 chunk 提示。
- Impeccable 單次檔案掃描只有兩筆未修改區段的既有警告（ApiChatConsole.tsx 灰階字色、index.css 預覽邊線）；完成審查為 ship，沒有要求修正項目。文件核對確認沿用既有 token，不建立新設計系統。
- 驗證使用合成資料，沒有寫入公司正式紀錄。尚未驗證實體手機軟鍵盤、Safari 與獨立 PWA。
