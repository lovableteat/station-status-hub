# Data-center 手機操作區重排

使用者標註手機畫面上方三列操作區，要求 UI 重做。延續黑底青綠與原功能，只調整手機的呈現、導覽與空間分配；不改場景幾何、相機、模型、同步、權限、工作回報與保存流程。

- 頁首保留機房名稱、專案／站點與工作回報入口，統一觸控尺寸與主要動作層級。
- 手機流程列改成目前完成數與完整下一步摘要；點開可閱讀、選取原來五個步驟，仍使用同一個處理函式。桌面保留原流程列。
- 專案站點、機櫃設備、模型庫、2D／3D 切換維持原回呼，改成一行文字按鈕。320px 可省略裝飾圖示，功能文字始終可見。
- 以隔離合成資料驗證 518、390、320px 與桌面，核對下一步、全部步驟、說明、四個入口及回報切換；場景與正式資料不試寫。執行相關測試、型別、Lint、建置、單次設計掃描，再提交部署並核對正式資源。

## 驗證結果

- 158 項 Data-center 相關檢查通過。新增互動檢查確認摘要隨進度更新、選擇步驟後關閉選單、使用原回呼，以及切回桌面時保留五步列。
- TypeScript、修改元件 ESLint、正式建置與 diff 檢查通過。建置仍有既有大型 chunk 提示；單次設計掃描只有未修改區段的既有寬度動畫警告。
- 實際元件與 WebGL 使用合成機房、通用機櫃與隔離資料來源，已目視 607、518、390、320px 以及 1440px。窄版沒有頁面橫向溢出，四個操作入口高 44px；手機場景填滿剩餘高度，518×884 的畫布高 569px。
- 已操作五步流程、專案站點、機櫃設備、模型庫、2D／3D、使用說明、工作回報與返回場景；未提交正式資料。畫布伸展樣式僅套用小於 1024px，模型幾何與相機計算保持原邏輯。
- 尚未實測實體手機的觸控手勢、Safari、軟鍵盤或獨立 PWA。
