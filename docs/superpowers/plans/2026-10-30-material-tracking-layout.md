# 追蹤視窗 UI 重排

依使用者提供的參考圖，只修改呈現，不改資料與功能。

- 左側：票號／連結、九種狀態與不新增紀錄選項、申請資訊、更新人、追蹤說明、圖片。
- 右側：目前已儲存狀態、時間、操作者與歷史時間軸；保留歷史展開、圖片預覽與下載。
- 桌面採兩欄、緊湊表頭與固定儲存列；窄版回單欄，不縮小文字。
- 使用者追加料件資料參考圖：預設左側表單、右側 SPEC，另保留「表格（一列）」切換。這是本次對既有只用單排表格規則的明確 UI 調整；15 欄原名、意義、順序與欄位綁定共用，切換不儲存或更動草稿。
- 狀態僅改用原生 radio 直接選取，沿用 updateDraft 與既有儲存／驗證；不新增自動儲存、狀態推算、資料庫欄位或權限變更。
- 驗證：既有草稿、圖片非同步／跨帳號隔離、唯讀與共用儲存測試；桌面／手機目視、原生鍵盤選擇、取消／重開、型別、Lint、建置與部署。
