# 績效考核打包與單欄貼上

2026-10-10

## 操作

- 員工自評填寫區及已送出狀態提供「匯出完整 ZIP」。ZIP 包含 Excel、HTML、整合自評文字及實際佐證附件、圖片；不會儲存或提交考核。
- 主管與部長從既有匯出名單勾選人員，再使用「匯出完整 ZIP」。只包含目前篩選範圍內已勾選、已儲存且可讀取的人員。主管／部長 ZIP 的 Excel 保留人員總覽首頁及姓名到個人頁的連結。
- 「一鍵複製全部實績」依 IDP、OKR、KPI 排序並逐筆編號，保留全文、換行、證明連結與檔名，方便貼入只有一個大框的考核系統。複製內容不混入主管評語或分數，不改寫為 S／T／A／R 四個欄位。
- 「檢視整合文字」在原頁展開可選取的文字，沒有額外視窗。瀏覽器拒絕剪貼簿時，自動展開並選取文字，供 Ctrl／⌘ + C 複製。
- 匯出的 HTML 每位員工也有複製按鈕及可展開的整合文字，解壓後在瀏覽器開啟即可使用；Excel 格式、首頁與個人頁保留原樣。
- 本機匯出及複製也包含尚未按「新增實績」的最後輸入，但不改變原編輯表單或提交狀態。獨立 Excel／HTML 匯出仍保留。

## 檔案內容

ZIP 根目錄包含報表、全部人員整合自評文字及檔案索引，另外有每人一份文字檔。佐證附件依人員、類別及實績收進資料夾，原始位元組保留；同名檔案以編號區分，清除路徑分隔字元避免跨資料夾。

外部 HTTPS 證明網址保留為連結，不抓取 SharePoint 或其他外部網站。ZIP 的佐證檔案來自考核中已保存的附件及圖片。

匯出沿用原有排除主管退回紀錄、原因與退回附件的範圍。一般主管／部長匯出另收進可辨識為目前逐項回覆的附件；曾出現在退回歷史的附件不再重複收進。主管整體附件目前屬退回附件，仍排除。員工自評匯出不包含任何主管附件或評分。

## 完整性與效能

- 打包只在使用者按下匯出時載入 JSZip；不新增背景資料請求或對其他使用者廣播。
- 部門完整資料讀取沿用每次最多兩筆的既有流程。打包顯示讀取、建立報表及壓縮進度。
- 下載前及非同步階段再次確認資料保護狀態。鎖定、切換存取範圍或權限變動後，不下載先前取得的資料。
- 未讀取完整考核、附件損毀或檔案缺失時，整個 ZIP 匯出失敗並顯示原因，不會把部分檔案當作成功。
- 為限制瀏覽器工作記憶體，匯出內容上限 128 MiB、最多 2,000 個佐證檔案；附件仍沿用單檔 4 MiB 的既有規則。超過上限時明確提示，不省略檔案。
- 不新增資料庫欄位、migration、雲端附件上傳或可公開取得人事資料的網址。

## 驗證

34 項相關測試通過。單元測試驗證 ZIP 解壓後的 Outlook 郵件及圖片位元組、同名檔案、路徑、主管資料範圍、姓名連結、故障及權限變動；複製測試驗證全文、既有文字格式、最新輸入與多人人員順序。React 渲染互動驗證一鍵複製、剪貼簿拒絕後的原頁選取、背景複製失效、部門勾選範圍及匯出進度。App／Node 型別檢查、正式建置與 git diff --check 通過；ESLint 沒有錯誤，既有六項 hook 警告保留。

Browser plugin 在本次會話未提供，使用既有 Playwright 與已安裝 Chrome，在獨立本機測試頁及模擬人員資料驗證桌面與手機；實際下載 ZIP 並解壓確認，未使用正式人事資料。正式系統與外部上傳網站的實際人事檔案未在測試中上傳。
