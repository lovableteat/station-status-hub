# 元件禁制區

在 2D 畫布對元件按右鍵，選擇「設定元件禁制區」。設定後同一選項會變成「調整元件禁制區」。右鍵選單不再顯示「元件操作」標題；複製、旋轉、鎖定、刪除仍保留。

## 使用方式

- 上、右、下、左距離皆為 mm，從元件本身的邊緣向外延伸。0 代表該側不延伸，負數與空白不可套用。
- 四側是元件未旋轉時的本身方向；旋轉元件後，禁制區與控制點一起旋轉。
- 選取元件後，拖曳橘色邊界控制點可單獨調整一側。Alt 暫停吸附。
- 控制點取得鍵盤焦點後，上／右方向鍵增加距離，下／左減少；Shift 以 0.1 mm 微調。
- 「移除禁制區」只移除該元件的禁制區，不會刪除元件。
- 每次套用、移除或完成一次拖曳都是一次復原步驟。儲存沿用工具列「儲存」或 Ctrl+S。

## 資料與規則

`PcbPlacedComponent.keepout` 是可選的四側距離；舊文件無此欄位時維持原行為。禁制區幾何由元件位置、尺寸、旋轉及距離推算，不另存獨立物件，因此移動、群組移動、旋轉、複製和刪除都保持關聯。原先獨立禁制區仍維持獨立編輯。

元件禁制區只限制同層的其他元件，不會與所屬元件自行產生碰撞。碰撞及超出板框會由既有 DRC 呈現；自動放置會避開禁制區。2D、3D、相容 3D 使用相同幾何。既有 JSON、模板、本機與遠端儲存 payload 保留此欄位，無須資料庫遷移。
