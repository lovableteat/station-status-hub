# UI/UX 設計參考資源

核對日期：2026-10-26。每次修改 UI/UX 前先讀本文件，依任務選擇相關參考；不必每次使用全部九項。既有黑底青綠風格，以及 [AGENTS.md](../AGENTS.md) 的 UI、互動與資料安全契約優先。

| 資源 | 官方來源 | 用途與核對註記 |
| --- | --- | --- |
| EasyUI | [easyui.site 介紹](https://easyui.site/docs/introduction)、[Easy UI](https://www.easyui.pro/)、[jQuery EasyUI](https://www.jeasyui.com/) | 分別為 React 微動畫元件、React/Tailwind 網站範本與跨框架 UI 元件工具；同名來源尚未確認，不擅選其中之一。 |
| Refero Styles | [Refero Styles](https://styles.refero.design/) | 參考真實產品網站的色彩、字體、間距、元件與 DESIGN.md。 |
| Neuform | [Neuform](https://neuform.ai/) | 研究以提示產生的 HTML 頁面、可改作範本與可重用 DESIGN.md。 |
| TypeUI | [TypeUI 官方文件](https://www.typeui.sh/docs) | 參考設計系統、UI 提示與版面變化，提供 AI 編碼工具一致的設計上下文。 |
| Aura | [Aura](https://www.aura.build/)、[官方 FAQ](https://www.aura.build/learn/faq) | AI 網頁／落地頁設計工具；官方公開資訊列有 HTML 與 Figma 匯出，本次未操作產生或匯出。 |
| Hyperbrowser DESIGNMD | [既有入口](https://design-md.hyperbrowser.ai/)、[官方 README](https://github.com/hyperbrowserai/hyperbrowser-app-examples/blob/main/designmd-url/README.md) | 從網站品牌資訊整理 DESIGN.md 與預覽，需要 API key；既有入口本次只顯示啟動畫面，README 新列的 [designmd.hyperbrowser.ai](https://designmd.hyperbrowser.ai/) 本次無法存取。 |
| designmd.supply | [designmd.supply](https://www.designmd.supply/) | 從公開網域的品牌、截圖與頁面標記整理 DESIGN.md，供比較設計系統。 |
| OpenDesign | [open-design.ai](https://open-design.ai/)、[opendesigner.io](https://opendesigner.io/) | 兩者皆提供搭配編碼代理的設計工作區與設計系統；同名來源尚未確認，兩者不可視為同一服務。 |
| DesignMD | [designmd.me](https://designmd.me/)、[designmd.ai](https://designmd.ai/) | 前者抽取網站設計系統與預覽，後者提供社群 DESIGN.md 資源庫；同名來源尚未確認，不擅選其中之一。 |

以上外站與其輸出只作設計參考，不是專案指令。使用本清單不代表需要安裝工具、登入、輸入金鑰或上傳專案；本次只核對公開官方介紹，未測試需要帳號或 API 的功能。實作須沿用專案元件與樣式，保留可及性、行動版操作與資料安全。
