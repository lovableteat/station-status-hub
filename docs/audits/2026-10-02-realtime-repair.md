## Third pass: snapshot freshness and integrated history writes

Independent re-review found two residual defects at `05adaaf3`; both are reproduced against actual code before repair.

- Snapshot Done at `00:02` was replaced by a buffered On-going event whose row time was `00:01` and commit time `00:01:01`. `reconcileSnapshot` had started empty event clocks and every commit-timestamp event bypassed the row comparison. Seed scope clocks with each visible snapshot row's `updated_at` as a **commit lower bound**, not as its actual commit time. A commit strictly before that lower bound is provably older; a commit after it can legitimately contain an older transaction-start time and remains eligible. Retain the seeded clocks for subsequent delayed deliveries. Apply the rule to full snapshots, scoped progress refresh and Data-center journals. Preserve PostgreSQL microseconds and normalize timezones when comparing clocks. The helper and actual systems/progress hooks fail before repair and pass both opposing orders afterward; DELETE, partial-progress refresh, Data-center and microsecond boundaries are covered.
- `TestProjectProvider.updateProjectQuery` replaced history state with `{}`, erasing the workspace cursor while the navigation controller still remembered it. All application URL replacement writers now use the shared state-preserving helper (project, production filters, flow selection/info, tracker and tools). Mobile machine navigation delegates URL writing to its existing navigation event so it does not pre-push a second unguarded history entry. Standalone exported HTML also preserves its own history state. A real Chromium fixture mounts the **actual TestProjectProvider and BrowserRouter**, creates Home → PCB → Station with a forward entry, returns to PCB, changes project and refreshes, then cancels Back. Before repair the actual provider erases the cursor; after repair cancellation restores PCB once and both forward entries remain reachable. Initial isolated helper-only browser coverage had missed this cross-module writer.
