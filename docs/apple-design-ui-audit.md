# Apple 深色介面一致性檢查

2026-10-06。以 `frontend-design` 實作，並以 `apple-design` 檢查回應、層級、材質、留白與觸控尺寸。

## 共用規則

| 項目 | 統一規則 |
| --- | --- |
| 底色 | 石墨黑；卡片、次要操作與浮動視窗依序使用深灰材質 |
| 主操作 | 藍色；一般次要操作為灰色；危險操作為紅色 |
| 圓角 | 表單／按鈕 12px，卡片／選單 16px，視窗 24px，關閉按鈕為圓形 |
| 留白 | 主要區塊間距 24px；內容區 16–28px；操作之間至少 12px |
| 文字 | 系統字型；一般內文有清楚行高；次要文字維持可讀對比 |
| 考核識別 | IDP 紫、OKR 藍、KPI 粉紅；主管回覆使用琥珀色，保留文字標籤 |
| 行動操作 | 主要按鈕及關閉按鈕至少 44px；圖示按鈕的寬度同樣至少 44px |
| 動態 | 按壓立即回應；視窗 150–200ms；移除無必要的光暈、浮動與大範圍模糊 |
| 可及性 | 保留鍵盤焦點與元件原有焦點管理；支援減少動態、減少透明及提高對比 |

共用 tokens 在 `src/index.css`。正式元件維持原本 API 與互動；只加上 `data-ui` 樣式定位。舊版硬編碼的藍黑 utility 材質接到同一套 tokens；後台、測試計畫與 PCB 面板的自有 CSS 也使用共用材質。PCB 圖層與模型的業務色彩及幾何資料不在此版重新設計。
